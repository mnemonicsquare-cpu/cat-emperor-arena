# Кот-Император: Дворцовая зачистка

Автономная двухуровневая браузерная игра. Первый уровень остаётся пиксельным платформером, а после победного ролика начинается отдельный ретро-FPS во внутренних покоях Кота-Императора. Все игровые файлы находятся в `dist/`; сборка и установка зависимостей для запуска не нужны.

## Уровень II — ретро-FPS

Второй уровень использует программный raycasting-рендер во внутреннем разрешении 320×180 (с автоматическим снижением до 256×144 на медленном устройстве). Карта включает стартовые покои, коридор, центральный зал, две боковые комнаты, закрытую имперской печатью галерею и финальный зал. В правой комнате находится рычаг; после его активации открывается путь к финальному бою и выходу.

Противники перенесены из первого уровня с разным поведением: культисты преследуют и атакуют вблизи, колдуны держат дистанцию, выпускают медленные снаряды с малым физическим ядром и телепортируются только в свободную, достижимую и видимую игроку точку, а зомби не получает stun, долго замахивается, продолжает наступать и заметно регенерирует. Все параметры здоровья, скорости, урона, обнаружения и атаки находятся в одном объекте `ENEMY_TYPES` в `dist/level2-core.js`.

Оружие реагирует на нажатие сразу, имеет автоматический огонь при удержании, вспышку, отдачу камеры и корпуса, гильзу и синтезированный звук. Есть ограниченные боеприпасы, аптечки, открывающиеся двери, интерактивный рычаг, компактный HUD, пауза, смерть, быстрый рестарт и экран победы со временем, количеством уничтоженных мышей и счётом.

Для прямой проверки без прохождения первого уровня откройте `http://localhost:8000/?level=2`.

На компьютере: `WASD` — движение, мышь — обзор, ЛКМ — огонь, `E` — действие, `R` — рестарт, `Esc`/`P` — пауза. На телефоне и планшете внутри игрового viewport одновременно работают аналоговый стик слева, свободный свайп справа, удерживаемая кнопка огня и контекстная кнопка действия. Стандартные жесты страницы внутри игры отключены; горизонтальная ориентация использует почти всю доступную высоту.

FPS-графика находится в `dist/assets/fps/`: прозрачное оружие направлено от игрока в сцену, три ряда персонажей содержат состояния idle/движение/атака/реакция/смерть, отдельные листы содержат предметы и 4×2 дворцовых текстур. Исходники сохранены в `dist/assets/fps/source/`, описание запросов — в `scripts/fps-asset-prompts.md`, повторная упаковка — `node scripts/pack-fps-assets.cjs`.

Два культиста начинают на полу, три патрулируют случайные платформы нижнего, среднего и верхнего ярусов. При перезапуске площадки выбираются заново; любая из 16 платформ может стать стартовой. Зомби медленно передвигается, имеет восемь единиц здоровья, восстанавливает одну единицу за 12 секунд и наносит двойной урон после долгого замаха. Получение урона не отбрасывает живого зомби, не сбивает замах и не вызывает стоп-кадр. Регенерацию показывают зелёные частицы, индикатор над головой и «+1».

Фон дворца — единая сцена от пола до сводов, созданная встроенным генератором изображений. Файл: `dist/assets/backgrounds/palace_interior.webp`. Задание для изображения: фронтальный пиксельный интерьер высокого готического научно-фантастического дворца Кота-Императора, многоярусные галереи, колонны, кошачьи витражи и статуи, багряные знамёна, бронза и свечной свет; без персонажей, игровых платформ и надписей.

Проверки без установки зависимостей:

```bash
node tests/game-regression.cjs
node tests/mobile-combat.cjs
node tests/motion-navigation.cjs
node tests/level2-core.cjs
node tests/level2-assets.cjs
```

Они проверяют патрули, преследование, привязку кадров к поверхности, регенерацию, непрерываемый замах зомби, многопальцевый ввод и его отмену, паузу, расчёт размеров для телефонов/планшетов, препятствия для снарядов и выбор места телепортации. Это проверки кода, не прогон на физических iPhone/iPad.

Колдуны атакуют медленными снарядами синей энергии, когда оказываются с котом на одном уровне. После полученного урона выживший колдун выбирает случайную свободную платформу в текущем экране, с запасом для всего спрайта. Близкие платформы тоже доступны: ограничений на дальность переноса и минимальное расстояние до кота больше нет, запрещено только пересечение персонажей. Пол не является целью телепортации. Место повторно проверяется перед переносом: камера или другие персонажи могли сдвинуться. При отсутствии места колдун получает урон без запуска телепортации. Исчезновение и появление занимают суммарно 1,25 секунды и сопровождаются голубым туманом.

Ядро столкновения снаряда — 6×4, его рисунок сохранён. Снаряды сталкиваются с полкой платформы, а не с прозрачным пространством под плиткой.

## Персонажи

Игра загружает четыре листа `dist/assets/sprites/*_clean.webp`: 24 кадра кота, 16 культиста, 12 колдуна и 16 зомби. Кадры изолированы от соседних рисунков и разложены с прозрачными отступами. Старые листы сохранены как исходники. `dist/atlas.js` задаёт области кадров, опорные точки лап и масштаб персонажа, чтобы прозрачные поля не вызывали парения.

В стойке кота один хвост. Новые шаговые циклы кота, культиста и зомби используют четыре фазы: вынос ноги, перенос второй ноги, противоположный вынос и обратный перенос. Фаза шага зависит от пройденного по поверхности расстояния; в воздухе мышь держит одну позу. При сходе с платформы культист сохраняет направление до завершения схода, что устраняет дрожание и зависание на краю.

Исходники движения: `cat_motion_source.webp`, `cultist_motion_source.webp`, `zombie_motion_source.webp` в `dist/assets/sprites/`. Созданы встроенным генератором изображений. Задание: сохранить облик персонажей, сделать четыре последовательные фазы шага с чередованием ближней и дальней ноги, боковой вид вправо, одинаковый масштаб; для кота дополнительно стойка с одним хвостом. При упаковке RGB-маска фона кота очищается, целый слой корпуса и оружия совмещается с фазами ног. `scripts/source-atlas.json` хранит области остальных исходных кадров. Пересборка: `node scripts/pack-sprites.cjs > dist/atlas.js`; проверка прозрачных отступов всех 68 кадров: `node scripts/check-sprites.cjs`. Для этих двух инструментов нужен `@napi-rs/canvas`; сама игра зависимостей не требует.

Изображения созданы встроенным генератором. Задание: сохранить золотую броню, солнечную корону, светлую морду и красный плащ кота, красный балахон культиста и сине-фиолетовое одеяние колдуна с посохом; повысить детализацию ткани, меха и металла до уровня зомби; боковой вид вправо, прозрачный фон, кадры ожидания, движения, атак и гибели. Области кадров измерены по альфа-каналу. Для повторного измерения используется `scripts/atlas-metadata.cjs` (нужен `@napi-rs/canvas`; для самой игры он не нужен).

Игра рендерится во внутреннем разрешении 1280×720 с сохранением чёткой пиксельной графики.
После победы проигрывается финальный ролик; его можно пропустить клавишей `Esc` или кнопкой на экране.
Во время боя звучит зацикленная композиция `Litany of the Iron Giants`; музыку можно включать и выключать клавишей `M`.

## Локальный запуск

```bash
python3 -m http.server 8000 -d dist
```

После запуска откройте `http://localhost:8000`.

## Управление

`A/D` или стрелки — движение, `W`/`Space` — прыжок, `J` — меч, `K` — луч, `M` — музыка, `F` — развернуть игру, `R` — перезапуск, `P` — пауза.

На сенсорных устройствах автоматически появляется панель под ареной: движение слева, меч, луч и прыжок справа. Одновременные касания поддерживаются, клавиатура продолжает работать и с включённой панелью. Кнопка ✥ включает или скрывает панель вручную. При прерывании касания, смене ориентации или уходе из вкладки удержания освобождаются; бой ставится на паузу при потере фокуса. Возобновление — кнопка «Продолжить» или `P`.

Поле сохраняет пропорции 16:9. Размер учитывает видимую область браузера, панели управления и безопасные отступы экрана. Горизонтальная ориентация удобнее на телефоне, но вертикальная также доступна. Если системный Fullscreen API недоступен, кнопка разворачивает игру внутри страницы; скрытие интерфейса Safari или принудительный поворот не требуются.

## Откат обновления

Состояние игры непосредственно до добавления FPS сохранено в ветке `backup/before-level2-fps-20260908` на коммите `fcec68c809060991d0e03bbdf4008a30f838427b`. Весь второй уровень публикуется отдельным коммитом, поэтому безопасный откат выполняется через `git revert` этого коммита; первый уровень при этом остаётся в истории без изменений.

Версия до адаптации управления и обновления персонажей сохранена в ветке `backup/before-character-combat-upgrade-20260906`, коммит `169488a26ede8a4eb2d9dbc874da133fb8d1d7a8`.

Исправления анимации и навигации от 8 сентября идут отдельным коммитом `Fix sprite isolation, gait cycles, ledge pursuit and visible platform teleports`. Его можно отменить командой `git revert`, сохранив предыдущее обновление управления и боя (`afc1a05`).

Изменения управления, спрайтов и боя публикуются одним коммитом `Add mobile controls and detailed characters; refine sorcerer and zombie combat`. Чтобы вернуть прежнюю игру без переписывания истории, выполните `git revert` для этого коммита и отправьте новый коммит в `main`. Не используйте принудительную перезапись `main`: резервная ветка остаётся неизменной.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой публичный репозиторий, например `cat-emperor-arena`.
2. В каталоге проекта выполните:

```bash
git remote add github https://github.com/USERNAME/cat-emperor-arena.git
git push -u github main
```

3. На странице репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в поле **Source**.
4. Workflow `.github/workflows/pages.yml` автоматически опубликует содержимое `dist/`. Следующие обновления достаточно отправлять обычным `git push github main`.
